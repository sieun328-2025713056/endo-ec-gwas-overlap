
# Final Output Tables and Provenance

## Overview

This document records the intermediate and downstream output files associated with the endometriosis-spectrum and endometrial cancer GWAS workflow.

It distinguishes:

1. Historical workflow outputs
2. Final covariance-aware inference
3. Sensitivity-analysis verification
4. Secondary conjFDR outputs
5. Exploratory colocalization and GTEx outputs

Internal filenames such as `table_s1`, `table_s7`, and `table_s14` are workflow-development labels. They do not necessarily correspond to the final manuscript supplementary-table numbering.

Not all files listed here are distributed or regenerated by the public repository.

## 1. Historical LDSC-derived outputs

The following files are generated by:

`scripts/07_make_ldsc_tables_from_logs.py`

- `results/tables/table_s1_ldsc_h2_qc_from_logs.tsv`
- `results/tables/table_s2_ldsc_rg_from_logs.tsv`
- `results/tables/table_s3_rg_approx_difference_test_from_logs.tsv`
- `results/tables/table_s7_ldsc_rg_multiple_testing_correction.tsv`

These files document:

- LDSC SNP-heritability quality control
- Six bivariate genetic correlations
- Historical approximate genetic-correlation difference tests
- Historical multiple-testing summaries

The historical approximate difference tests used:

`sqrt(SE1^2 + SE2^2)`

This approach does not incorporate sampling covariance arising from shared cancer GWAS data or non-independent endometriosis-spectrum estimates.

The BH-FDR correction across six genetic-correlation tests is retained as historical or supporting output.

These historical tests and corrections are not the final primary inferential framework.

## 2. Final primary inference: GenomicSEM

The final primary inference uses covariance-aware genetic-correlation heterogeneity testing.

Reference script:

`scripts/12_rgmodel_final_tests.R`

Required saved intermediate objects:

- `results/rgmodel_allEC.rds`
- `results/rgmodel_EEC.rds`

These RDS files are not distributed in the public repository.

GenomicSEM `rgmodel()` provides:

- `R`: genetic-correlation estimates
- `V_R`: sampling covariance matrix

The final tests comprise:

- Two primary omnibus Wald tests
- Six post-hoc pairwise contrasts
- Bonferroni correction across two primary omnibus tests
- Joint Holm correction across six post-hoc contrasts

### Final omnibus results

| Outcome | ChiSq(2) | P |
|---|---:|---:|
| allEC | 8.155546 | 0.016945159 |
| EEC | 9.632358 | 0.008097669 |

The primary significance threshold was P < 0.025.

### Selected pairwise results

ENDO versus ADENO:

| Outcome | Difference in rg | Raw P | Holm P |
|---|---:|---:|---:|
| allEC | -0.21221502 | 0.012022315 | 0.06011158 |
| EEC | -0.26318497 | 0.006044072 | 0.03626443 |

Script 12 calculates and prints the final statistics from saved inputs.

Its presence does not imply that the repository distributes a corresponding final results TSV file.

Historical approximate-difference tables should not be substituted for these covariance-aware results.

## 3. LDSC sensitivity-analysis outputs

### Block-sensitivity analysis

Reference script:

`scripts/13_rgmodel_sensitivity.R`

The public reference script reads saved LDSC RDS files for the 100-block and 400-block settings.

The principal analysis used 200 blocks.

| Setting | allEC omnibus P | EEC omnibus P |
|---|---:|---:|
| 100 blocks | 0.01151326 | 0.007853592 |
| 200 blocks | 0.016945159 | 0.008097669 |
| 400 blocks | 0.02482712 | 0.01197984 |

The modified public script does not save or overwrite the GenomicSEM RDS results.

The public copy has passed syntax parsing but has not been independently rerun end-to-end after repository adjustments.

### ENDO-only MAF sensitivity

Reference script:

`scripts/15_maf05_rgmodel_verification.R`

The upstream ENDO LDSC input was prepared using:

`--maf-min 0.05`

The munged ENDO input retained 1,064,328 SNPs.

The downstream verification reads:

- `ldsc_allEC_4trait.rds`
- `ldsc_EEC_4trait.rds`

from the configured MAF LDSC input directory.

### Verified MAF-sensitivity results

| Outcome | ChiSq(2) | Omnibus P | ENDO-ADENO Holm P |
|---|---:|---:|---:|
| allEC | 7.411255 | 0.02458479 | 0.08779310 |
| EEC | 8.821470 | 0.01214624 | 0.05680075 |

The downstream calculations matched previously reported values within an absolute tolerance of 1e-5.

The verification script prints results and does not create output tables or overwrite saved analysis objects.

Detailed verification:

`docs/maf05_rgmodel_validation.md`

The verification does not establish that the original GWAS munging and LDSC analyses can be independently reproduced from the public repository alone.

### Updated final reference implementation

Reference script:

`scripts/14_coloc_chr12_final_reference.R`

The final analysis used:

- Adenomyosis P-values and minor allele frequencies
- Median eligible variant-level `AD_N = 33460.65`
- Assumed adenomyosis case fraction `s = 0.5`
- Aligned EC beta estimates and squared standard errors
- Outcome-specific EC sample sizes and case fractions
- Priors `p1 = 1e-4`, `p2 = 1e-4`, and `p12 = 1e-5`

### Final conditional results

| Outcome | Eligible SNPs | PP.H4 |
|---|---:|---:|
| allEC | 3159 | 0.9931782 |
| EEC | 3158 | 0.9880625 |

rs7959150 had the highest conditional SNP.PP.H4 for both outcomes.

The final reference script prints results.

SNP-level posterior export is optional and requires:

- `EXPORT_COLOC_POSTERIOR=1`
- An existing `COLOC_POSTERIOR_DIR`

When enabled, the intended output filenames are:

- `adeno_allEC_final_snp_posterior.tsv`
- `adeno_EEC_final_snp_posterior.tsv`

These optional output files are not automatically generated by default.

The original derivation of adenomyosis effective sample size and the appropriateness of the assumed case fraction remain unresolved.

The public reference script has not been independently rerun end-to-end following its repository adjustments.

## 7. Reproducibility limitations

- Raw GWAS summary statistics are not redistributed.
- Large LD/reference resources and intermediate LDSC objects are not included.
- Historical and final-analysis scripts have different inferential roles.
- Not all downstream output tables are generated by the public scripts.
- Some public reference scripts have not been independently rerun end-to-end.
- The overall-endometriosis LDSC intercept deflation remains unresolved.
- The adenomyosis colocalization effective sample size and case-fraction assumption require methodological clarification.
- Internal table filenames should not be equated with final manuscript supplementary-table numbering.

See `docs/reproducibility_notes.md` and `docs/interpretation_limits.md` for further details.
