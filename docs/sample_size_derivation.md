# Sample size derivation notes

This project used publicly available GWAS summary statistics.

## Overall endometriosis excluding 23andMe

The released European-ancestry overall endometriosis summary statistics used in this study excluded 23andMe.

The case-control count for this file was not directly reported in the released summary statistics file. It was inferred by subtracting the 23andMe contribution from the reported EUR combined endometriosis meta-analysis sample size in Koller et al. (2026).

- EUR combined endometriosis in Koller et al. (2026): 99,407 cases and 1,093,534 controls
- 23andMe endometriosis GWAS contribution: 37,183 cases and 251,258 controls
- Inferred 23andMe-excluded overall endometriosis sample size: 62,224 cases and 842,276 controls

This value should be described as inferred or estimated, not as a directly reported file-level sample size.

## Other exposure GWAS datasets

- Adenomyosis: 8,753 cases and 415,718 controls
- Endometriosis without adenomyosis: 6,627 cases and 283,316 controls

## Outcome GWAS datasets

- All endometrial cancer: 12,906 cases and 108,979 controls
- Endometrioid endometrial cancer: 8,758 cases and 46,126 controls
