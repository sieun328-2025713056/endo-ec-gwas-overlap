# Data sources

This repository contains code for reproducing the GWAS summary-statistics workflow. Raw GWAS summary statistics, LD reference files, and large intermediate outputs are not redistributed.

## Exposure GWAS summary statistics

Exposure summary statistics were obtained from Koller et al. (2026):

- Overall endometriosis, European ancestry, excluding 23andMe
- Adenomyosis, European ancestry
- Endometriosis without adenomyosis, European ancestry

## Outcome GWAS summary statistics

Outcome summary statistics were obtained from O'Mara et al. (2018):

- All endometrial cancer
- Endometrioid endometrial cancer

## Data redistribution

This repository does not redistribute raw GWAS summary statistics or restricted-access data. Users should obtain the source data from the original study repositories and comply with the data-use terms of the original providers.
